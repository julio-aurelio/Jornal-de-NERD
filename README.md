# 📰 Jornal de NERD

Página de notícias sobre games, filmes e cultura nerd, feita no começo do meu curso para praticar **HTML** e **CSS** puros.

![Logo do Jornal de NERD](img/Jonal%20de%20NERD.jpg)

## Sobre o projeto

A ideia foi recriar o layout de um portal de notícias, com:

- **Destaque principal** com vídeo do YouTube incorporado (trailer de *Um Filme Minecraft*)
- **Notícias menores** em cards com imagem, título e resumo
- **Espaço de publicidade** entre as seções
- **Efeito hover** nos títulos das matérias

Foi aqui que eu treinei a montagem de layout com **Flexbox**, a organização da página em blocos (`header`, `main`, `footer`) e a estilização em um arquivo CSS separado.

## Tecnologias

- HTML5
- CSS3 (Flexbox)

## Estrutura

```
├── index.html   # estrutura da página
├── style.css    # estilos e layout
└── img/         # logo, imagens das notícias e publicidade
```

## Como rodar

Não precisa instalar nada:

1. Clone o repositório
   ```bash
   git clone https://github.com/julio-aurelio/projeto_jornal-main.git
   ```
2. Abra o arquivo `index.html` no navegador.

## O que eu aprendi

- Estruturar uma página com tags semânticas
- Posicionar elementos com Flexbox
- Incorporar vídeos com `<iframe>`
- Separar conteúdo (HTML) de aparência (CSS)
